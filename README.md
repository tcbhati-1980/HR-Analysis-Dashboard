# 👨‍💼 HR Analytics Dashboard | Power BI Project

## 📌 Project Overview
This project showcases an interactive **HR Analytics Dashboard** built in Power BI to analyze employee data and generate actionable insights for better workforce management.

The dashboard focuses on employee distribution, attrition analysis, performance trends, and key HR metrics.

---

## 🎯 Objectives
- Analyze employee demographics  
- Track attrition and retention trends  
- Identify factors affecting employee turnover  
- Monitor department-wise performance  
- Support data-driven HR decisions  

---

## 📊 Dashboard Features
- 👥 Total Employees Overview  
- 📉 Attrition Rate Analysis  
- 🏢 Department-wise Employee Distribution  
- 🎓 Education Field Analysis  
- 💼 Job Role Insights  
- 📅 Age Group & Experience Analysis  
- 💰 Salary Distribution  

---

## 🔍 Key Insights
- High attrition observed in specific departments  
- Younger employees show higher turnover rates  
- Certain job roles have lower retention  
- Salary and experience impact employee stability  
- Education background influences job distribution  

---

## 🛠️ Tools & Technologies Used
- Power BI  
- DAX (Data Analysis Expressions)  
- Microsoft Excel
